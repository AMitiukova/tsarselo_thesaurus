# Тезаурус Царского Села

Тезаурус имён собственных (персоналии, артефакты, геообъекты), собранный
обкачкой сайтов. Медиаархив по нему сверяет написание имён собственных в
транскриптах видеороликов о музее.

Пока реализован сбор с **tsarselo.ru**: статья «Александровский дворец» из
раздела [«Адреса»](https://www.tsarselo.ru/разделы/адреса) и все статьи
(и документы .pdf/.docx/.odt/.doc/.rtf), на которые она ссылается.

## Запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python scrape_tsarselo.py                       # раздел «Адреса» → «Александровский дворец», глубина 1
python scrape_tsarselo.py --depth 2             # плюс ссылки из вложенных статей
python scrape_tsarselo.py --article-url "https://www.tsarselo.ru/..."   # статья по прямой ссылке
python scrape_tsarselo.py --no-wiki             # без поиска кандидатов в Wikidata
python -m pytest tests -q                       # офлайн-тесты
```

Страницы кэшируются в `.cache/`, поэтому повторный прогон (или `--offline`)
сеть не нагружает. Если `data/thesaurus.json` уже есть, новые объекты
дописываются в него: дубли не создаются, нумерация продолжается.

## Формат записи

```json
{
  "id": "2P00001",
  "site": 2, "site_name": "tsarselo.ru",
  "section": "P", "section_name": "personality",
  "seq": 1,
  "name_ru": "Джакомо Кваренги",
  "name_en": "Giacomo Quarenghi",
  "name_en_source": "wikidata_candidate",
  "name_en_translit": "Dzhakomo Kvarengi",
  "role_type": "архитектор",
  "keywords": ["архитектор"],
  "aliases": ["Кваренги"],
  "forms": ["Джакомо Кваренги", "Кваренги"],
  "wiki": {
    "status": "candidate", "verified": false,
    "candidates": [{"qid": "Q...", "label_ru": "...", "label_en": "...",
                    "description_ru": "...", "ruwiki": "...", "enwiki": "...", "score": 1.9}]
  },
  "sources": [{"url": "https://www.tsarselo.ru/...", "title": "Александровский дворец"}],
  "article_url": "https://www.tsarselo.ru/...",
  "mentions": 3
}
```

* **id** = цифра сайта (`1` — tzar.ru, `2` — tsarselo.ru) + буква раздела
  (`P` — personality, `A` — artefact, `G` — geoobject) + порядковый номер
  (отдельный счётчик для каждой пары сайт+раздел).
* **name_ru** — начальная форма (Natasha: «Александру Павловичу» → «Александр Павлович»).
  Для персоналий короткая форма («Кваренги») сливается с полной и попадает в `aliases`.
* **forms** — формы, как они встретились в тексте; полезны для сопоставления с транскриптами.
* **role_type** — для персоналий: архитектор, художник, скульптор, хранитель, императрица,
  великий князь… (по умолчанию «историческая личность»); для артефактов: архитектурный
  объект, интерьер, скульптура, живопись, графика, ДПИ…; для геообъектов: город,
  населённый пункт, парк/сад, улица/площадь, водный объект… Роль берётся из определения
  в собственной статье объекта («X — итальянский архитектор»), иначе из контекста упоминаний.
* **name_en** — английская метка лучшего кандидата Wikidata, если она есть,
  иначе транслитерация (`name_en_source` показывает, откуда значение).
* **wiki** — кандидаты из Wikidata **без проверки** (`verified: false`); их нужно подтвердить вручную.
* Дубли проверяются по всему тезаурусу, в том числе среди записей другого сайта.

В `meta.last_run` файла лежат список обойденных страниц и заголовки статей,
тип которых определить не удалось (`unclassified_titles`): их стоит разобрать вручную.

## Устройство

| Файл | Назначение |
|---|---|
| `scrape_tsarselo.py` | CLI |
| `thesaurus/tsarselo.py` | разбор HTML tsarselo.ru: поиск статьи в разделе, текст, ссылки, документы |
| `thesaurus/extractor.py` | NER (Natasha) + правила: PER → P; LOC/ORG → A или G по слову-типу; «Китайский театр»; картина «…» |
| `thesaurus/config.py` | коды сайтов/разделов, словари ролей и типов |
| `thesaurus/store.py` | id, проверка дублей, слияние, JSON |
| `thesaurus/wiki.py` | кандидаты Wikidata |
| `thesaurus/fetcher.py` | HTTP с кэшем и паузой |

Разметку tsarselo.ru проверить на живом сайте при разработке не удалось, поэтому
основной текст ищется по списку типичных селекторов (`CONTENT_SELECTORS` в
`thesaurus/tsarselo.py`), а если ни один не подошёл, берётся блок с наибольшим
количеством текста. После первого реального прогона стоит проверить `meta.last_run.pages`
(поле `chars`) и при необходимости добавить в начало списка точный селектор.
